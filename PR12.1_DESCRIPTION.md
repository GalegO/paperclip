# PR 12.1: Generic Local File-based Agent Sync

## 🧠 Thinking Path

This PR evolves that concept into a fully dynamic system, allowing human administrators to define *any* local directory on their machine as a source of truth for agent instructions. The system can now scan this directory, automatically construct AI agents from the subfolders, and upload all associated Markdown instructions directly via the UI, completely decoupling the feature from the Paperclip source code.

## 📝 What Changed

**Technical Changes:**
- **Shared Configuration (`packages/shared/src/types/instance.ts`)**: Added new experimental configuration flags `enableCustomAgentFileSync` and `customAgentFileSyncPath` along with their Zod validators to securely persist the targeted sync directory path.
- **Backend API & Service (`server/src/services/custom-agent-sync.ts`)**: Created the `customAgentSyncService` that performs the heavy lifting:
  - Validates the provided directory path.
  - Scans subfolders, treating each as an individual Agent.
  - Recursively reads all `.md` instruction files within those subfolders.
  - Upserts the agents into the database (automatically granting them a $100 monthly budget and assigning the native `process` adapter).
  - Triggers the `agentInstructionsService.materializeManagedBundle` to compile these files into active agent memory bundles.
- **Endpoint Routing (`server/src/routes/instance-settings.ts`)**: Registered the `POST /instance/settings/experimental/custom-agent-sync` endpoint, protected by administrator authorization checks.
- **UI Updates (`ui/src/pages/InstanceExperimentalSettings.tsx`)**: Added the new "Custom Agent File Sync" panel to the Experimental tab, complete with path inputs and company selection checkboxes.

**Functional Changes & User Experience:**
- **UI Control Panel**: Administrators can navigate to Instance Settings > Experimental to find a new panel. When toggled on, it reveals a text input for an "Absolute Directory Path".
- **Multi-Tenant Flexibility**: The UI includes a list of available Companies with checkboxes, allowing administrators to choose exactly which companies will receive the synchronized agents.
- **One-Click Sync**: Clicking the "Sync Now" button triggers the backend to parse the local filesystem and instantaneously build or update the workforce in the database based purely on the local Markdown files.

## 🧪 Verification

- Verified that TypeScript successfully typechecks the new entities against existing database schemas (e.g., `AgentLike`, Drizzle schemas).
- The code is modular and successfully processes nested directory structures.
- Tested the endpoint locally ensuring proper administrator authorization is enforced.

## ⚠️ Risks

- **Medium**. Allowing backend processes to recursively read arbitrary absolute paths provided by the UI carries path-traversal and file-read risks if not strictly sanitized. Access is heavily restricted to Instance Administrators only.
